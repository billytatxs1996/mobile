# 移动工作台 产品需求文档

## 一、需求概述

### 1.1 文档目的与读者

本文档面向**开发人员**，用于实现「移动工作台」移动端产品的功能与交互。通过明确业务背景、功能范围、页面结构与非功能要求，保证开发与产品、业务理解一致，便于排期、实现与验收。

### 1.2 产品定位与目标

**产品名称**：移动工作台  

**产品定位**：面向电力/运维现场人员的**移动端工作门户**，整合作业安全、巡视、跳闸处置与管理决策等能力，支持在手机端完成工作票查看、安措执行、作业过程与终结、人机协同任务处理、跳闸事件处理及告警查看等核心场景。

**核心目标**：

- **智能安全**：工作票查看，安措执行、作业过程、作业终结的填报与状态管理（待开始/进行中/已完成）。
- **智能巡视**：人机协同任务（待核实/已完成）的查看、现场核实与结果填报；巡视进度指标的可视化与任务看板。
- **智能跳闸**：跳闸快报查看、故障确认与故障处理的填报与只读查看，支持按事件状态切换表单/结果页。
- **管理决策**：重点工作、业务看板、质量看板等看板与统计信息。
- **统一入口**：工作台作为首页聚合各业务入口；底部导航支持告警中心、工作台、小智（智能助手）的全局切换；支持角色切换与作业项/跳闸事件选择等基础能力。

### 1.3 功能内容总览（按工作台 / 告警中心 / 小智划分）

#### 工作台

- **管理决策**
  - **重点工作**：展示当前重点工作与任务进度，支持按站点/时间维度查看与筛选。
  - **业务看板**：展示巡视、作业、安措等业务统计（待开始/进行中/已完成数量）及待审核等提醒。
  - **质量看板**：展示终端在线率、站点排名（缺陷、在线、使用等）等质量相关指标。
- **智能安全**
  - **工作票**：查看工作票基本信息、班组人员、安全措施等，按所选作业项展示，仅只读。
  - **授权申请**：围绕临时增员、车辆授权、门禁授权、锁具授权等场景，负责人员可发起授权申请并填写明细，许可人员在本 Tab 内对授权申请进行审核（通过/驳回），并查看授权总体情况及审核结果。
  - **安措执行**：安措布置拍照（工器具检查、防护佩戴、现场布置、技术交底）+「安措执行描述」填写与提交；按作业状态（待开始/进行中/已完成）和角色（负责人员/许可人员）控制可编辑与只读，**不在此 Tab 发起或审核授权许可**。
  - **作业过程**：更新进度、异常上报及**变更许可**提交与审核；负责人员可提交进度、异常和变更许可，许可人员仅在本 Tab 对变更许可做「通过/驳回」审核。
  - **作业终结**：完工信息拍照与作业总结填报，支持终结信息的审核结果展示；按作业状态（待开始/进行中/已完成）和角色控制可编辑与只读。支持选择作业项、按状态筛选，角标展示进行中数量。
- **智能巡视**
  - **人机协同**：待核实任务列表与已完成任务列表，支持搜索；进入任务详情可查看缺陷信息并做现场核实（拍照、填写分析及备注、提交属实/不属实）。
  - **进度指标**：展示巡视完成率、待核实/已完成/属实/不属实数量、简单数据分析与最近完成任务列表。
- **智能跳闸**
  - **跳闸快报**：查看跳闸事件列表及详情（时间、设备、类型、电流、描述、波形图等）；支持选择跳闸事件，未读角标提示。
  - **故障确认**：对所选事件进行故障确认填报（照片、故障类型/等级、描述、建议）；未确认/待处理或已处理时展示不同表单或只读结果。
  - **故障处理**：处理方案、处理人员与时间、设备材料、处理过程与照片、处理结果等；已处理事件展示只读结果页，未确认/待处理为可填表单。支持选择跳闸事件，角标区分未确认/待处理数量。
- **其他**
  - 工作台首页展示日期、欢迎语，支持角色切换（如安全人员、巡视人员、管理人员）；各业务入口带角标时表示有待办或未读数量。

#### 告警中心

- **安全告警**：展示安全相关告警列表与数量，无告警时提示「暂无安全告警」；可进入告警详情查看。
- **巡视告警**：展示巡视相关告警列表与数量，支持点击查看告警详情。
- **跳闸告警**：展示跳闸相关告警列表与数量，与智能跳闸未读/待处理数据联动；支持查看告警详情。
- 底部导航「告警」入口进入告警中心，角标数字表示未读或待处理告警总数。

#### 小智

- **智能助手**：对话式交互，支持用户提问与回复；可配置欢迎语与场景提示；支持**数据问答**与**图表展示**（如告警数量、完成率、巡视数据、趋势图、柱状图、饼图等），回复可为模拟数据或对接接口。
- **场景与历史**：支持按场景（如巡视应用、分析应用等）切换或发起对话；可查看历史对话侧边栏或列表；回复支持多种表述随机展示，避免固定话术。
- 底部导航「小智」入口进入，作为全局智能助手入口，与工作台、告警并列一级导航。

### 2.1 工作台

#### 2.1.1 工作台首页

**页面布局**

- **顶部栏**：左侧显示当前日期时间（文本）；右侧为欢迎语（一行文案）+ 角色切换按钮（图标）。欢迎语示例：「Hello! 小鱼儿，你好！」。
- **主体**：自上而下四个区块，每块有区块标题 + 若干应用入口（图标 + 名称），入口以网格排列。
- **无底部 Tab**：本页为整页内容，底部导航由应用全局提供（告警 / 工作台 / 小智）。

**功能内容与样式**

- **第一区块「管理决策」**
  - 标题：文案「管理决策」。
  - 入口 1：图标（黄色）+ 文案「重点工作」；点击后进入「重点工作」页面。
  - 入口 2：图标（蓝色）+ 文案「业务看板」；点击后进入「业务看板」页面。
  - 入口 3：图标（绿色）+ 文案「质量看板」；点击后进入「质量看板」页面。
- **第二区块「智能安全」**
  - 标题：文案「智能安全」。
  - 入口 1：图标（蓝色）+ 文案「工作票」+ 角标（右上角小圆点/数字）；角标数字 = 当前「进行中」状态的作业项数量，为 0 时不显示角标，大于 99 显示「99+」。点击后进入「智能安全」页面且默认显示「工作票」Tab。
  - 入口 2：图标（绿色）+ 文案「授权申请」+ 角标（规则同上）。点击后进入智能安全页面且默认显示「授权申请」Tab。
  - 入口 3：图标（绿色）+ 文案「安措执行」+ 角标（规则同上）。点击后进入智能安全页面且默认显示「安措执行」Tab。
  - 入口 4：图标（橙色）+ 文案「作业过程」+ 角标（规则同上）。点击后进入智能安全页面且默认显示「作业过程」Tab。
  - 入口 5：图标（青色）+ 文案「作业终结」+ 角标（规则同上）。点击后进入智能安全页面且默认显示「作业终结」Tab。
- **第三区块「智能巡视」**
  - 标题：文案「智能巡视」。
  - 入口 1：图标（青色）+ 文案「人机协同」+ 角标；角标数字 = 待核实任务数量，为 0 时不显示。点击后进入「人机协同」页面。
  - 入口 2：图标（紫色）+ 文案「进度指标」；无角标。点击后进入「巡视进度指标」页面。
- **第四区块「智能跳闸」**
  - 标题：文案「智能跳闸」。
  - 入口 1：图标（紫色）+ 文案「跳闸快报」+ 角标；角标 = 未读跳闸事件数量，为 0 不显示。点击后进入「智能跳闸」页面且默认显示「跳闸快报」Tab。
  - 入口 2：图标（橙色）+ 文案「故障确认」+ 角标；角标 = 状态为「未确认」的跳闸事件数量，为 0 不显示。点击后进入智能跳闸页面且默认显示「故障确认」Tab。
  - 入口 3：图标（绿色）+ 文案「故障处理」+ 角标；角标 = 状态为「待处理」的跳闸事件数量，为 0 不显示。点击后进入智能跳闸页面且默认显示「故障处理」Tab。

**数据展示**

- 日期时间：展示当前系统日期时间，格式与本地一致（如「2026-02-24 14:30」或仅日期）。
- 欢迎语：展示当前登录或选中的角色对应问候语，如「负责人员 - 张三」等，随角色切换而更新。
- 角标数据来源约定：智能安全中带角标的入口（工作票、授权申请、安措执行、作业过程、作业终结）的角标与「选择作业项」列表里状态为「进行中」的条数一致；人机协同角标与待核实任务条数一致；跳闸三个角标与跳闸事件列表中未读数量、未确认数量、待处理数量分别一致。进入工作台时需按上述规则刷新各角标。

**按钮与交互**

- **角色切换按钮**：点击后弹出「角色切换」弹窗。弹窗内标题「切换角色」，下列表：每行一个选项，文案如「负责人员 - 张三」「许可人员 - 李四」「管理人员 - 王五」。用户点击某一项后：欢迎语更新为该角色对应文案，弹窗关闭。弹窗支持点击遮罩或外部区域关闭。
- **各应用入口**：点击后直接进入对应页面，无二次确认。进入智能安全或智能跳闸时，若该页依赖「当前选中的作业项」或「当前选中的跳闸事件」，则按业务规则自动选中一条（如智能安全选列表第一项，智能跳闸按当前 Tab 优先选待处理或已处理等），并刷新内容。

**边界与异常**

- 若某角标数据源列表为空或数量为 0，对应入口不显示角标。
- 从子页面返回时：智能安全、智能跳闸、人机协同、重点工作、业务看板、质量看板、巡视进度指标等页面的「返回」按钮均返回本工作台首页；选择作业项页、选择跳闸事件页的返回仅关闭自身，回到智能安全或智能跳闸页面。

#### 2.1.2 选择作业项页面

**页面布局**

- 全屏从右侧滑入覆盖在智能安全页之上。顶部为蓝色导航栏：左侧返回箭头，中间标题「选择作业项」，右侧无按钮。主体为白色区域：上方为搜索栏（输入框 + 筛选图标按钮），下方为作业项列表，纵向滚动。

**功能内容与样式**

- **搜索栏**：一个单行输入框，占位符「作业项名称或工作票号模糊搜索」；右侧一个筛选图标按钮。输入框输入时，列表实时过滤：仅展示「作业项名称」或「工作票号」包含输入文字的项（不区分大小写）；输入为空时展示全部项。
- **筛选按钮**：点击后从底部弹出「筛选条件」弹窗。弹窗内包含：标题「筛选条件」、关闭叉号；「作业时间」：一个日期选择框（年-月-日）；「作业状态」：四个可选项「全部」「进行中」「待开始」「已完成」；底部「重置」「确认」按钮。重置：清空日期、状态选为「全部」。确认：按所选条件过滤作业项列表并关闭弹窗。
- **作业项列表**：每条为一张卡片。卡片内从上到下显示：作业项名称（加粗）、工作票号（如「工作票号：WD-2026-02-001」）、作业时间（如「作业时间：2026-02-11 09:00 - 17:00」）、状态（如「状态：进行中」）。每条卡片需携带：作业项 ID、作业项名称、作业状态（进行中/待开始/已完成），供智能安全页使用。列表数据与工作台「智能安全」角标所用作业项列表一致。

**数据展示**

- 每条列表项展示：作业项名称、工作票号、作业时间、状态。数据来源为作业项列表；筛选与搜索均在前端或后端过滤该列表后展示。

**按钮与交互**

- **返回按钮**：点击后本页滑出隐藏，重新露出智能安全页面。返回后智能安全页应使用用户在本页选中的作业项刷新当前 Tab 内容；若用户未选过，则保持进入选择页前的选中项不变。
- **列表项点击**：点击某一条后，该条视觉上变为选中态（如背景或边框高亮），且记录为「当前选中作业项」。再次点击同一项保持选中。仅能选中一条。
- **弹窗关闭**：筛选弹窗的关闭叉号、底部「取消」或点击遮罩可关闭弹窗；确认后关闭并应用筛选。

**边界与异常**

- 列表为空时：展示空态文案（如「暂无作业项」）。此时智能安全页在未选任何项的情况下，应展示占位或提示「请先选择作业项」，或自动选中列表第一条（若后来有数据）。
- 打开方式：仅当用户在「智能安全」页面点击右上角「切换项目」时打开本页，打开时列表为全部作业项或上次筛选结果。

#### 2.1.3 智能安全页面

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「智能安全」，右侧「切换项目」按钮（图标或文字）。下方为五个 Tab：工作票、授权申请、安措执行、作业过程、作业终结；点击 Tab 切换下方内容区。内容区为可滚动区域，根据当前 Tab、当前选中作业项的状态（待开始/进行中/已完成）及当前角色（负责人员/许可人员）展示只读信息或可填表单。

**数据与展示规则**

- 当前选中作业项：来自「选择作业项」页面用户点击的那一条；若用户从未打开选择页，则进入本页时自动选中作业项列表的第一条。每条作业项包含：作业项 ID、作业项名称、工作票号、作业时间、状态（进行中/待开始/已完成）。

##### 授权申请页面（Tab：授权申请）

**页面布局**

- 主体根据作业项状态与当前角色分为多种展示：**已完成**为只读多区块（授权总体情况 + 审核结果）；**待开始/进行中**下负责人员为授权申请表单（临时增员、车辆授权、门禁授权、锁具授权等），许可人员为授权申请明细 + 审核区块。

**数据展示规则**

- 授权申请相关字段（授权类型、授权对象、时长、说明等）按作业项 ID 在前端本地存储一份记录，用于在不同 Tab 之间切换时保持填写内容与审核结果一致。
- 负责人员提交授权申请后，记录状态从草稿变为「待审核」，许可人员审核通过/驳回后写入审核状态、审核意见、审核人、审核时间，并在本 Tab 与角标中统一展示。
- 若当前作业项尚无授权记录，本页展示空态或提示文案（待开始状态），不展示旧作业项的数据，避免跨作业串数据。

**已完成时的展示**

- 展示工作项名称，以及「临时授权总体情况」「授权明细」「审核结果」等信息区块：包括是否存在临时授权、授权类型、授权说明、审核状态、审核人、审核时间、审核意见等，仅只读，无按钮。

**许可人员视角**

- **待开始**：仅展示工作项名称及提示「当前作业项尚未提交授权申请，无需审核」等，无表单与审核操作。
- **进行中 / 已完成**：展示授权申请明细（如授权类型、人员/车辆/门禁/锁具信息、授权时长、说明等）与审核区块：审核意见输入域 + 按钮「通过」「驳回」。审核完成后展示审核结果（状态、审核人、时间、意见），负责人员可在同一 Tab 查看。

**负责人员视角（待开始/进行中，可编辑）**

- 首先展示当前工作项名称；下方为**临时授权申请**表单区域，可支持多种授权类型（如临时增员、车辆授权、门禁授权、锁具授权），通过页内小 Tab 或按钮切换不同授权类型的表单。
- 各授权类型的表单一般包含：基础信息（如人员姓名/车牌号/授权区域等）、授权时长、授权说明等字段。
- 底部提供按钮「提交授权申请」「保存草稿」等：待开始下按钮置灰，进行中可点击。提交后进入待审核状态，由许可人员在同一 Tab 内审核。

**按钮与交互**

- 负责人员在本 Tab 内新建或编辑授权申请，点击「提交授权申请」提交后，将当前作业项的授权申请状态更新为待审核，并提示成功；点击「保存草稿」仅本地保存填写内容，不触发审核流程。
- 许可人员在本 Tab 内仅对授权申请进行审核：点击「通过」或「驳回」后，记录审核状态、审核人、时间和审核意见，并给出提示，授权申请明细随之更新为审核结果。

**边界与异常**

- 在作业状态为「待开始」时，本页所有提交按钮（包括「提交授权申请」「保存草稿」「通过」「驳回」等）应为禁用，仅允许查看或预填，不允许真正提交或审核。
- 授权申请关键字段未填写完整时，点击提交应给出明确校验提示，并阻止提交。
- 提交或审核时如果接口失败或网络异常，应提示失败原因，并保留当前填写内容与状态，不误提示成功或误改状态。

##### 安措执行页面（Tab：安措执行）

**页面布局**

- 主体根据作业项状态与当前角色分为多种展示：**已完成**为只读多区块（负责人员与许可人员看同一套内容）；**待开始/进行中**下负责人员为可编辑表单（待开始时提交类按钮置灰），许可人员可查看安措布置与执行描述，并对安措执行进行审核（通过/驳回）。

**数据展示规则**

- 安措布置拍照与「安措执行描述」按作业项 ID 在本地存储一份记录，负责人员提交或保存草稿后，后续再次进入本 Tab 时按记录还原展示。
- 许可人员对安措执行的审核结果（通过/驳回、审核意见、审核人、审核时间）按作业项 ID 一并存储，审核后负责人员与许可人员均可查看审核结果；已完成状态下展示的安措布置信息、执行描述及审核结果来自前述记录或后端返回的最终结果。
- 已完成或已提交审核时，执行情况说明等展示须有具体内容：若已有提交内容则展示该内容，无则展示合理示例文案（如「现场已按要求完成安全工器具检查、个人防护装备佩戴、作业现场布置及安全技术交底，各项安措执行情况正常」），不展示为「无」或留空。
- 若当前作业项从「进行中」切换为「已完成」，本页仅展示最终记录，不再出现拍照与提交按钮；无记录时可按模板展示默认示例文案与示例图片。

**已完成时的展示**

- **第一块**：工作项名称（一行只读）。
- **第二块：安措布置信息**
  - 区块标题：「安措布置信息」。
  - 四项，每项包含：标签（如「安全工器具检查」）、状态「已完成」、一张示例或实际上传的照片。四项为：安全工器具检查、个人防护装备佩戴、作业现场布置、安全技术交底。
- **第三块：安措执行描述**
  - 区块标题：「安措执行描述」。
  - 展示：执行情况说明（多行只读），描述现场安措执行情况；内容来自负责人员提交或保存的文案，若无则展示合理示例，不展示为「无」。无按钮。
- **第四块（若存在审核）**：安措执行审核结果（审核状态、审核人、审核时间、审核意见），只读。无按钮。
- 照片可点击全屏查看；全屏时点击空白或关闭按钮退出。

**许可人员视角**

- **待开始**：仅展示工作项名称及提示「当前作业项尚未提交安措执行信息」或「无需审核」等，无安措表单、无审核操作。
- **进行中**：展示工作项名称、安措布置信息、安措执行描述（只读）。若负责人员已提交安措且未审核，则展示**安措执行审核**区块：审核意见输入、按钮「通过」「驳回」；审核后展示**安措执行审核结果**（审核状态、审核人、审核时间、审核意见）。不在此 Tab 进行授权许可相关操作。
- **已完成**：与负责人员看同一套只读内容（安措布置信息、安措执行描述、审核结果），无提交与审核按钮。

**待开始/进行中时的展示（负责人员可编辑）**

- **第一块**：工作项名称（一行只读）。
- **第二块：安措布置拍照**
  - 区块标题：「安措布置拍照」。
  - 四条 measure 项，每条结构相同：
    - 左侧/上方：标题（如「安全工器具检查」）+ 说明文案（如检查某某设备所需安全工器具是否齐全、完好）。
    - 右侧/下方：按钮「拍照」、按钮「确认」。
  - 四条分别为：安全工器具检查、个人防护装备佩戴、作业现场布置、安全技术交底。说明文案可根据作业项类型（10kV/主变压器/GIS/继电保护等）略有差异。
  - **拍照**：点击后调起相机或相册，选择/拍摄后上传照片并展示在该条下。**确认**：点击后将该条标记为已完成（可展示勾选或「已完成」标签）。待开始状态下「拍照」「确认」置灰不可点；进行中可点。
- **第三块：安措执行描述**
  - 区块标题：「安措执行描述」。
  - **执行情况说明**：多行文本，占位符如「请描述安措执行情况，如现场检查结果、存在问题及处理情况等」，选填。
  - 底部按钮：「提交安措」（主按钮）、「保存草稿」（次按钮）。待开始下两按钮置灰；进行中可点。提交后按业务约定更新状态或提示成功。

**按钮与交互**

- 「拍照」按钮：点击后调起相机或相册，用户选择/拍摄照片后，在对应的那条安措下方展示缩略图；缩略图支持点击全屏查看。
- 「确认」按钮：在该条已经有至少一张照片的前提下允许点击；点击后，将该条安措标记为已完成（界面上可通过「已完成」标签或勾选标识体现）。
- 「提交安措」按钮：在作业状态为「进行中」时可点击，用于提交安措执行描述及布置完成状态；在状态为「待开始」时按钮呈灰色，不可点击。
- 「保存草稿」按钮：在状态为「进行中」时可点击，用于仅保存当前填写内容（包括执行情况说明、已拍摄照片等）；在状态为「待开始」时置灰不可用。
- 许可人员「通过」「驳回」：仅对负责人员已提交的安措执行进行审核；通过或驳回后给出提示，审核结果写回记录，负责人员可查看审核结果。

**边界与异常**

- 当作业状态为「待开始」时，本页所有提交类按钮（包括各条「拍照」「确认」以及「提交安措」「保存草稿」）均应为不可点击，防止用户在未开工时误操作。
- 若用户未拍照就点击「确认」，应弹出提示（例如「请先完成拍照」），并保持该条安措处于未完成状态。
- 提交安措或保存草稿时，如出现接口错误或网络异常，应有错误提示，并保留用户已有的填写内容和照片，不误清空或误提示成功。
- 照片上传后需在对应条目下展示并可全屏查看。已完成或已审核时，执行情况说明等展示须有具体文案，不展示为「无」或留空。

##### 作业过程页面（Tab：作业过程）

**页面布局**

- 主体根据作业项状态与当前角色分为多种展示：**已完成**为只读多区块（含作业进度、异常情况、变更许可及审核结果）；**待开始/进行中**下负责人员为可编辑多区块（更新进度、异常上报、变更许可），许可人员可查看进度与异常，且**仅对变更许可进行审核**；待开始时所有提交类按钮置灰。

**数据展示规则**

- 作业进度（状态、百分比、描述）、异常上报（类型、描述、时间、状态）以及变更许可（原因、说明、审核信息）都按作业项 ID 存入本地记录，避免在 Tab 切换或返回后丢失。
- 「更新进度」「上报异常」「提交变更」会覆盖或追加到对应记录中；许可人员在本 Tab 的变更许可审核结果也写回同一记录，供负责人员只读查看。
- 已完成状态下展示的数据优先使用已有记录；若记录为空，可按默认模板构造合理示例值，仅作演示，不影响后端真实实现。

**已完成时的展示**

- **第一块**：工作项名称（一行只读）。
- **第二块：作业进度信息**：最终状态、完成百分比（如 100%）、进度描述（多行只读）。
- **第三块：异常情况**：异常记录（有则展示，无则「无异常」等文案）。
- **第四块：变更许可**：变更原因、变更说明、审核状态、审核人、审核时间（有则展示，无则「无」或「不作变更」）。无按钮。

**许可人员视角**

- **待开始**：展示工作项名称及「变更许可审核」区块，文案为「当前作业项尚未提交变更许可信息，无需审核。」（与授权申请 Tab 的待开始提示风格一致。）
- **进行中 / 已完成**：展示工作项名称、作业进度信息、异常情况、**变更许可**（只读）。变更许可区包含：**变更许可申请内容**（负责人员提交的变更原因、变更说明；若尚未提交则展示「当前暂无变更许可申请内容。」）、以及审核状态/审核人/审核时间/审核意见（已审核时）。若负责人员已提交变更许可且未审核，则展示**变更许可审核**区块：审核意见输入、按钮「通过」「驳回」；审核后展示审核结果。**许可人员仅在此 Tab 对变更许可进行审核，不对更新进度、异常上报做审核。**

**待开始/进行中时的展示（负责人员可编辑）**

- **第一块**：工作项名称（一行只读）。
- **第二块：更新进度**
  - 区块标题：「更新进度」。
  - **当前状态**：选择框，点击弹出底部弹窗，选项如「准备中」「进行中」「已完成」「暂停」，选后回填。
  - **完成百分比**：滑块，范围 0–100，拖动时旁侧或下方显示当前数值（如「0%」）。
  - **进度描述**：多行文本，占位符如「请描述当前进度情况」，选填。
  - 底部按钮：「更新进度」。待开始下置灰；进行中可点。
- **第三块：异常上报**
  - 区块标题：「异常上报」。
  - **异常类型**：选择框，点击弹出弹窗，选项如「设备异常」「人员异常」等，选后回填。
  - **异常描述**：多行文本，占位符如「请详细描述异常情况」，选填。
  - **异常现场拍照**：一条 measure（标题 + 说明 +「拍照」「确认」按钮）。
  - 底部按钮：「上报异常」「保存草稿」。待开始下置灰；进行中可点。
- **第四块：变更许可**
  - 区块标题：「变更许可」。
  - **变更原因**：选择框，点击弹出选项（如「不作变更」或具体原因），选后回填。
  - **变更说明**：多行文本，占位符如「请简要说明本次变更的内容和原因，便于许可人员确认」，选填。
  - 底部按钮：「提交变更」「保存草稿」。待开始下置灰；进行中可点。提交后由许可人员在作业过程 Tab 内进行变更许可审核（通过/驳回）。
- 本 Tab 内所有已展示照片支持点击全屏查看；全屏时点击空白或关闭按钮退出。

**按钮与交互**

- 「当前状态」选择框：点击后打开状态选择弹窗（如「准备中/进行中/已完成/暂停」），选中后回填显示文字；仅当用户点击「更新进度」时才一并提交给后端。
- 完成百分比滑块：用户拖动滑块时，旁边实时显示百分比数值（如「37%」）；松手后保持当前值，点击「更新进度」按钮时与状态和描述一起提交。
- 「更新进度」按钮：在作业状态为「进行中」时可点击，用于提交当前状态、百分比和进度描述；在状态为「待开始」时按钮应置灰不可点。
- 异常上报区：「异常类型」选择框点击打开异常类型弹窗，选中后回填；「拍照」「确认」用于异常现场照片；「上报异常」用于提交异常信息；「保存草稿」用于仅保存当前填写的异常信息。
- 变更许可区：「变更原因」选择框点击打开选项弹窗，选后回填；「提交变更」用于提交变更许可，提交后许可人员可见并可审核；「保存草稿」用于仅保存变更说明与原因，不提交审核。
- 许可人员「通过」「驳回」：仅对已提交的变更许可进行审核；通过或驳回后给出提示，负责人员可查看审核结果。

**边界与异常**

- 在作业状态为「待开始」时，本页所有提交类按钮（包括「更新进度」「上报异常」「保存草稿」「提交变更」「保存草稿」）均应禁用，仅允许用户预先查看或填写，不允许真正提交。
- 状态选择、异常类型、变更原因等弹窗关闭时，如用户未选中任何项，应保留原值，而不是置空。
- 提交进度更新、异常上报或变更许可时，如接口失败或网络异常，需要有明显的错误提示，并保留用户输入内容与已选照片，避免用户重填。
- 照片上传失败时，不应在界面上展示成功缩略图；已成功的照片应支持再次点击全屏查看。
- 当前状态、异常类型、变更原因等选项以产品/弹窗为准。提交类操作按业务约定提交并提示。

**本次调整说明（作业过程页面）**

- **许可人员待开始**：提示文案统一为「当前作业项尚未提交变更许可信息，无需审核。」，并增加「变更许可审核」区块标题，与授权申请 Tab 待开始样式一致。
- **许可人员进行中**：变更许可区明确拆分为「变更许可申请内容」与审核展示/操作：申请内容展示负责人员填写的变更原因、变更说明（未提交时展示「当前暂无变更许可申请内容。」）；已审核时展示审核状态、审核人、审核时间、审核意见；待审核时展示变更许可审核模块（审核意见输入、「通过」「驳回」按钮），逻辑与实现一致。

##### 作业终结页面（Tab：作业终结）

**页面布局**

- 主体根据作业项状态分为两种展示：**已完成**为只读多区块；**待开始/进行中**为可编辑多区块（完工拍照、提交终结），待开始时提交类按钮置灰。

**数据展示规则**

**已完成时的展示**

- **第一块**：工作项名称（一行只读）。
- **第二块：完工信息**
  - 区块标题：「完工信息」。
  - 四项，每项包含：标签（如「设备状态」）、状态或描述文案（如「正常运行」「整洁，无遗留物品」「已全部恢复」「无遗漏」）、一张示例或实际上传的照片。四项为：设备状态、工作现场、安全措施恢复、工器具。
- **第三块：作业总结**
  - 区块标题：「作业总结」。
  - 展示：总结内容（多行）、终结时间、备注。无按钮。
- **第四块：审核结果**
  - 区块标题：「审核结果」。
  - 展示：审核状态（已通过/已驳回）、审核人、审核时间、审核意见。无按钮。
- 照片可点击全屏查看。

**待开始/进行中时的展示（可编辑）**

- **第一块**：工作项名称（一行只读）。
- **第二块：完工拍照**
  - 区块标题：「完工拍照」。
  - 四条 measure 项，每条：标题 + 说明文案 +「拍照」按钮 +「确认」按钮。
  - 四条分别为：设备状态（拍摄设备运行状态，确保设备正常运行）、工作现场（拍摄工作现场，确保现场整洁无遗留）、安全措施恢复（拍摄安全措施恢复情况）、工器具有无遗漏（拍摄工器具有无遗漏，确保所有工具已收回）。拍照与确认逻辑同安措执行；待开始下置灰，进行中可点。
- **第三块：提交终结**
  - 区块标题：「提交终结」。
  - **作业总结**：多行文本，占位符如「请输入作业总结，包括完成的工作内容、遇到的问题及解决方法等」，必填或选填以产品为准。
  - **终结时间**：选择框，点击弹出日期时间选择，选后回填，默认可为当前日期时间。
  - **备注**：多行文本，占位符如「请输入备注信息」，选填。
  - 底部按钮：「提交终结」「保存草稿」。待开始下置灰；进行中可点。提交后按业务约定将作业项标记为已完成并刷新状态。

**按钮与交互**

- 完工拍照区四条（设备状态、工作现场、安全措施恢复、工器具有无遗漏）的「拍照」「确认」按钮：在作业状态为「进行中」时可操作，「拍照」用于采集照片并在对应条目下展示缩略图，「确认」用于在已有照片的前提下将该条标记为已完成；在状态为「待开始」时四条的拍照和确认按钮都应置灰禁止点击。
- 作业总结区：作业总结、终结时间、备注为用户可编辑字段；终结时间字段点击后打开时间选择弹窗，选中后回填显示。
- 「提交终结」按钮：点击前需通过必填校验（例如作业总结必填、终结时间有值），通过后提交终结信息，成功后将该作业项标记为已完成并切换为只读视图。
- 「保存草稿」按钮：允许在信息不完整时也可保存当前填写内容，不改变作业状态，用于中途暂存。

**边界与异常**

- 在作业状态为「待开始」时，「提交终结」和「保存草稿」按钮应为禁用状态，防止作业尚未开始时就被误终结。
- 用户未按要求完成关键内容（例如没有填写作业总结或未选择终结时间）就点击「提交终结」时，应给出明确校验提示，并阻止提交。
- 终结提交时，如果后端返回失败或网络异常，应在页面提示失败原因，并保留所有当前填写内容和照片，不自动清空或误将作业标记为已完成。
- 当终结成功后，该作业项的状态变为「已完成」，智能安全四个入口的角标以及「选择作业项」列表中的状态需要同步刷新，防止页面展示与实际状态不一致。
- 完工拍照四条与作业总结、终结时间、备注均随当前选中作业项；照片支持全屏查看。

#### 2.1.4 选择跳闸事件页面

**页面布局**

- 全屏从右侧滑入，覆盖在智能跳闸页之上。顶部导航栏：左侧返回箭头，中间标题「选择跳闸事件」。主体：上方搜索栏（单行输入框 + 筛选图标按钮），下方为跳闸事件列表，纵向滚动。

**功能内容与样式**

- **搜索框**：占位符「跳闸事件名称或设备名称模糊搜索」。输入时列表实时过滤：仅展示事件名称或设备名称包含输入文字的项；输入为空时展示全部。
- **筛选按钮**：点击后弹出跳闸筛选弹窗。弹窗内：跳闸时间（日期或时间范围）、状态（全部/未确认/待处理/已处理）等；「重置」「确认」按钮。确认后按条件过滤列表；重置清空条件。
- **事件列表**：每条为一张卡片。卡片内显示：事件名称（加粗）、跳闸时间、设备名称、状态（如「状态：已处理」）。每条需携带事件 ID、事件名称、时间、设备、状态，供智能跳闸页使用。列表数据与工作台「跳闸快报/故障确认/故障处理」角标所用跳闸事件列表一致。

**数据展示**

- 每条展示：事件名称、时间、设备、状态。数据来源为跳闸事件列表；筛选与搜索在该列表上过滤后展示。

**按钮与交互**

- **搜索框输入**：用户在搜索框中输入关键字（事件名称或设备名称）时，列表实时过滤，仅保留名称或设备包含关键字的事件；清空输入后恢复展示全部事件。
- **筛选弹窗操作**：点击筛选图标按钮打开筛选弹窗；在弹窗中选择跳闸时间和状态后，点击「确认」按钮，关闭弹窗并按条件过滤列表；点击「重置」按钮清空已选条件，列表恢复为未筛选状态。
- **列表项点击**：点击任一事件卡片后，该条在列表中高亮为选中态，并被记录为当前选中跳闸事件；同时关闭本页，返回智能跳闸页面，并用该事件刷新三个 Tab 的内容（跳闸快报/故障确认/故障处理的展示与只读或表单态均按该事件）。
- **返回按钮**：顶部返回按钮点击后，本页滑出隐藏，回到智能跳闸页面；如用户未切换选中事件，则保持原来的选中事件不变。

**边界与异常**

- 搜索条件或筛选条件过于严格导致列表为空时，需在列表区域展示明确空态文案，如「未找到符合条件的跳闸事件」；清空筛选和搜索条件后，恢复显示全部事件。
- 打开本页时，可保持上一次的筛选条件或重置为默认（全部）；设计需明确，避免用户困惑。
- 打开本页时，可高亮当前在智能跳闸中已选中的那条事件，帮助用户感知当前上下文。
- 关闭本页后，智能跳闸页面必须使用最新选中事件刷新展示；若用户未点击任何事件直接返回，则维持原选中事件不变。
- 若跳闸事件数据加载失败或为空，应展示「暂无跳闸事件」文案，并在搜索/筛选仍可交互但不会筛出任何结果。

#### 2.1.5 智能跳闸页面

（本页包含三个 Tab：跳闸快报 / 故障确认 / 故障处理。以下按 Tab 拆分说明，结构统一为：页面布局、功能内容与样式、数据展示规则、按钮与交互、边界与异常。）

##### 跳闸快报

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「智能跳闸」，右侧文字「选择跳闸事件」。下方 Tab：跳闸快报、故障确认、故障处理；默认展示跳闸快报内容区。
- 内容区：标题区显示当前跳闸事件名称；下方为信息卡片与波形图区域，**只读**，无表单、无提交按钮。

**功能内容与样式**

- 标题区：展示「事件名称」（来自当前选中事件）。
- 信息卡片（只读）：
  - 建议按 2 列栅格展示关键字段；长文案（如描述）占整行。
  - 字段建议包括（以产品/接口为准）：
    - 跳闸时间（yyyy-MM-dd HH:mm）
    - 设备名称/间隔
    - 跳闸类型/故障类型（若后端已给）
    - 电流/电压/保护动作信息（若有）
    - 事件状态（未确认/待处理/已处理）
    - 事件描述（多行只读）
  - 字段缺失展示「—」，避免空白/布局塌陷。
- 波形图/趋势图（只读）：
  - 有数据：展示波形缩略图或图表区域（可横向滑动查看多通道）。
  - 无数据：展示占位图 + 文案「暂无波形数据」。
- 图片/图表交互：支持点击全屏查看；全屏点击空白或关闭按钮退出。

**数据展示规则**

- 当前选中跳闸事件：来自「选择跳闸事件」页面用户点击的那一条；无选中事件时进入页自动选一条（优先未读/未确认等，以产品为准）。
- 数据口径：跳闸快报展示始终以「当前选中事件」为数据源；切换事件后需立即刷新本 Tab 内容。
- 已读：用户从选择事件页或告警中心进入本页后，该事件标记为已读；工作台「跳闸快报」角标与告警中心跳闸未读数随之更新。
- 统一标题：三大 Tab 的标题区事件名称必须一致，均来自当前选中事件，避免切换 Tab 后名称不一致。

**按钮与交互**

- 返回：返回工作台首页。
- 选择跳闸事件：打开「选择跳闸事件」页面；用户选一条并关闭选择页后，刷新本 Tab 展示。
- Tab 切换：仅切换内容区，不跳转页面。

**边界与异常**

- 无选中事件且事件列表为空：内容区展示「暂无跳闸事件」占位，避免空白。
- 事件名称缺失：以选择页选中条的显示名称为准，避免标题空白。
- 波形/图片加载失败：展示占位或失败提示，不影响其他字段展示。
- 数据加载慢：可在卡片区展示骨架屏/加载中（如 0.5–1s），避免白屏；加载完成后再渲染卡片与波形图。

##### 故障确认

**页面布局**

- 顶部导航栏与 Tab 结构同上；默认展示故障确认内容区时按当前选中事件渲染。
- 内容区：上方展示事件名称与摘要；下方为故障确认表单或只读结果区块，随事件状态切换。

**功能内容与样式**

- 未确认：可填表单（可编辑）。建议拆为 2–3 个区块：
  - **区块 1：现场照片**
    - 故障点照片（支持上传/拍照，支持多张；缩略图网格）
    - 设备状态照片（支持上传/拍照，支持多张）
    - 现场环境照片（支持上传/拍照，支持多张）
    - 每张图片支持：预览全屏、删除、显示上传失败状态（失败可重试）
  - **区块 2：故障信息**
    - 故障类型（选择框，弹窗选项，例如：设备故障/保护动作/通信异常/其他）
    - 故障等级（选择框，弹窗选项，例如：一般/重要/紧急）
    - 故障描述（多行文本，示例占位符「请描述现场故障现象与关键观察点」）
    - 处理建议（多行文本，示例占位符「请填写建议的处理措施或注意事项」）
    - 图片标记（可选）：对已上传照片进行简单标注（如圈选/箭头/文字），若当前版本不做编辑，可仅说明“支持后续扩展/不支持则隐藏入口”
  - **区块 3：操作按钮**
    - 底部按钮：「提交确认」「保存草稿」
- 待处理 / 已处理：只读结果（不可编辑）
  - 展示：确认人、确认时间、故障类型/等级、描述、建议、照片（只读可预览）、（可选）历史提交记录
  - 无提交按钮；如需要允许重新编辑，需明确业务约束（默认不支持）

**数据展示规则**

- 数据来源：以当前选中事件为数据源；故障确认表单填写内容按事件 ID 存储（本地记录或后端返回），切换事件时切换对应记录。
- 状态与展示：事件状态决定是否可编辑：未确认 → 表单可编辑；待处理/已处理 → 只读展示已确认结果。
- 状态流转：提交成功后按业务将事件状态更新（通常为未确认 → 待处理），并刷新工作台角标（故障确认角标=未确认数量）与事件列表状态。
- 草稿与提交：
  - 保存草稿：仅保存当前填写内容（含已上传照片引用），不改变事件状态、不进入待处理；再次进入本 Tab 时自动回填草稿。
  - 提交确认：写入确认结果并将事件状态更新为待处理（或后端返回的下一状态），提交成功后切换为只读展示。
- 时间格式：确认时间统一用 yyyy-MM-dd HH:mm:ss（或与全局时间组件一致）。

**按钮与交互**

- 返回：返回工作台首页。
- 选择跳闸事件：打开选择页，选中事件后刷新本 Tab（表单/只读态随状态变化）。
- Tab 切换：仅切换内容区；再次返回本 Tab 时仍以当前选中事件渲染。
- 保存/提交：保存用于暂存；提交用于提交确认结果并触发状态更新与提示（成功/失败）。
- 表单回填：从其他 Tab 返回或切换事件回来时，未提交的草稿应保留并回填；若切换到其他事件，需切换到该事件对应草稿/结果。

**边界与异常**

- 必填校验（建议）：
  - 故障类型：必选
  - 故障等级：必选
  - 故障描述：必填（最少 5–10 字）
  - 照片：至少上传 1 张（若产品要求更严格，可明确“故障点照片必传”）
  - 校验不通过时：在对应字段下方提示错误，并阻止提交
- 网络/接口失败：展示错误提示并保留已填内容与已选照片，避免重填。
- 状态不一致：若后端返回状态与本地不一致，以后端为准并刷新页面。
- 重复提交：提交过程中按钮置为 loading/disabled，防止连点；提交完成后恢复或跳转只读态。

##### 故障处理

**页面布局**

- 顶部导航栏与 Tab 结构同上；默认展示故障处理内容区时按当前选中事件渲染。
- 内容区：上方展示事件名称与摘要；下方为故障处理表单或只读结果区块，随事件状态切换。

**功能内容与样式**

- 未确认 / 待处理：可填表单（可编辑）。建议拆为 3–4 个区块：
  - **区块 1：处理方案**
    - 处理方案（多行文本，占位符「请填写处理方案与步骤」）

  - **区块 3：处理结果**
    - 处理结果（选择框：成功/部分成功/失败）
    - 恢复时间（日期时间选择框；仅当处理结果为成功/部分成功时可选或必填，按产品约定）

**数据展示规则**

- 数据来源：以当前选中事件为数据源；故障处理表单填写内容按事件 ID 存储（本地记录或后端返回），切换事件时切换对应记录。
- 状态与展示：未确认/待处理 → 表单可编辑；已处理 → 只读展示处理结果。
- 状态流转：提交成功后事件状态更新为已处理，并刷新工作台角标（故障处理角标=待处理数量）与事件列表状态。
- 事件名称一致性：本 Tab 内事件名称与跳闸快报、故障确认一致，均来自当前选中事件。
- 草稿与提交：
  - 保存草稿：仅保存填写内容，不改变事件状态；再次进入自动回填。
  - 提交处理：提交成功后写入处理结果并更新事件状态为已处理；页面切换为只读展示。

**按钮与交互**

- 返回：返回工作台首页。
- 选择跳闸事件：打开选择页，选中事件后刷新本 Tab（表单/只读态随状态变化）。
- Tab 切换：仅切换内容区；再次返回本 Tab 时仍以当前选中事件渲染。
- 保存/提交：保存用于暂存；提交用于提交处理结果并触发状态更新与提示（成功/失败）。
- 字段联动：
  - 处理结果为「失败」时，可隐藏/置灰恢复时间（或允许填写但不强制），避免逻辑冲突。
  - 提交后刷新：三个 Tab 均按新的事件状态重新渲染（故障确认/故障处理变只读）。

**边界与异常**

- 无选中事件：进入页时自动选一条再渲染；若列表为空则展示占位或提示。
- 必填校验（建议）：
  - 处理方案：必填
  - 处理人员：必填
  - 处理时间：必填
  - 处理结果：必选
  - 处理过程：建议必填或最少字数
  - 恢复时间：按处理结果与业务约定（成功/部分成功时必填）
- 网络/接口失败：展示错误提示并保留已填内容与已选照片，避免重填。
- 防连点：提交过程中按钮置为 loading/disabled，避免重复提交；失败后恢复可重试。

#### 2.1.6 人机协同页面

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「人机协同」。下方两个 Tab：待核实任务、已完成任务。每个 Tab 下：上方搜索框，下方任务列表（卡片列表，纵向滚动）。

**功能内容与样式**

- **搜索框**：占位符「任务名称或设备名称模糊搜索」。输入时对当前 Tab 的列表做过滤，仅展示任务名称或设备名称包含输入文字的项；空则展示全部。
- **筛选按钮**：搜索框右侧筛选图标按钮，与选择作业项页、选择跳闸事件页样式一致。点击后从底部弹出「筛选条件」弹窗。弹窗内包含：标题「筛选条件」、关闭叉号；**任务时间**：日期选择框（点击打开日期时间选择弹窗，选后回填）；**严重程度**：四个可选项「全部」「一般」「较严重」「严重」；**核实结果**（仅在「已完成任务」Tab 下展示）：三个可选项「全部」「属实」「不属实」。底部「重置」「确认」按钮。重置：清空任务时间、严重程度与核实结果（恢复为「全部」），并刷新当前 Tab 列表为未筛选状态、关闭弹窗。确认：按所选条件过滤当前 Tab 的任务列表并关闭弹窗；筛选与搜索可同时生效（先按筛选条件过滤，再在结果上做关键词搜索）。
- **待核实任务列表**：每条卡片展示任务相关摘要（如设备、位置、描述、时间、严重程度等），点击进入该任务的「人机协同任务详情」页面，且详情页展示为「待核实」态（含现场核实表单与确认按钮）。
- **已完成任务列表**：每条卡片展示任务摘要及核实结果等，点击进入任务详情页，且详情页展示为「已完成」态（只读，无操作按钮）。
- 列表数据与工作台「人机协同」入口角标一致：角标数字 = 待核实任务数量，为 0 时不显示角标。

**数据展示**

- 每条列表项展示：任务名称或设备、时间、位置、描述、状态（待核实/已完成）等，具体字段以产品设计为准。

**按钮与交互**

- **Tab 切换**：点击「待核实任务」「已完成任务」按钮切换列表区域，只影响当前页内列表展示，不跳转页面。
- **搜索框输入**：用户在对应 Tab 的搜索框中输入关键字时，列表实时过滤，仅显示任务名称或设备名称中包含关键字的任务；删除关键字或清空输入后，恢复显示当前筛选条件下的全部任务。
- **筛选弹窗操作**：点击筛选图标打开筛选弹窗；在弹窗中选择任务时间、严重程度（及已完成 Tab 下的核实结果）后，点击「确认」按条件过滤当前 Tab 列表并关闭弹窗；点击「重置」清空条件、刷新列表并关闭弹窗；关闭叉号或点击遮罩也可关闭弹窗。
- **列表项点击**：点击任一任务卡片，打开「人机协同任务详情」页面；详情页根据该任务是否已完成展示对应模式（待核实：可操作表单；已完成：只读结果）。
- **返回按钮**：顶部返回按钮点击后，返回工作台首页；从任务详情页返回时，返回到本页面并保持原来的 Tab（待核实或已完成），列表可按需要刷新最新状态。

**边界与异常**

- 待核实或已完成任一列表为空时，需在对应列表区域展示明确的空态文案（如「暂无待核实任务」「暂无已完成任务」），而不是空白。
- 工作台「人机协同」入口的角标数字为待核实任务数量；当该数量为 0 时，不显示角标。
- 从任务详情页返回时，如果任务状态已变更为已完成，应保证「待核实任务」列表中不再出现该任务，而在「已完成任务」列表中可见，避免状态不一致。

- **任务信息区**：设备名称、任务时间、位置、缺陷描述（多行文案）、分析结果、严重程度（如高/中/低）；缺陷图片：有图则展示缩略图（可点击全屏），无图则文案「无缺陷图片」。

  - 核实备注：多行文本，选填。

**按钮与交互**

- **返回**：返回人机协同页面（待核实/已完成列表），并刷新列表与工作台角标。

#### 2.1.8 巡视进度指标页面

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「人机协同进度」。主体从上到下依次为：数据分析标题 + 时间维度切换；整体完成率与进度条；关键指标数字行（待核实/已完成/属实/不属实）；图表或趋势分析区；「最近完成任务」列表。

**功能内容与样式**

- **时间维度**：右上角按钮「本周」「本月」，用于切换统计时间范围；默认选中「本周」。切换后页面所有统计数据（完成率、各类数量、图表、最近任务列表）按照新的时间范围重新计算展示。
- **完成率**：顶部一行显示当前时间范围内已完成任务数/总任务数对应的百分比，如「完成率 75%」，旁边可显示「X/Y 任务」的统计文案；下方为一条横向进度条，填充宽度与百分比一致。
- **关键指标行**：一行四个数字，分别为「待核实」「已完成」「属实」「不属实」任务数量；样式突出数字，标签文字较小。数量来源与人机协同模块中的任务统计一致。
- **图表/趋势分析区**：可采用简易柱状图/折线图/饼图组合，展示例如「本周每天完成任务数」「属实/不属实名称占比」等，具体图形由设计确定；无数据时展示灰色占位图或「暂无数据」文案。
- **最近完成任务列表**：标题「最近完成任务」。列表中每条展示设备名称、完成时间、核实结果（属实/不属实）等；点击可进入该任务的人机协同任务详情页，并以已完成只读态展示。

**数据展示规则**

- 数据范围：受时间维度影响（本周/本月）。本页所有统计与列表（完成率、关键指标、图表、最近完成任务）均以当前时间范围内的任务数据为口径。
- 完成率计算：完成率 \(=\frac{已完成任务数}{总任务数}\times 100\%\)。其中「总任务数」= 待核实任务数 + 已完成任务数；展示文案同时显示「X/Y 任务」。
- 关键指标口径：
  - 待核实：当前时间范围内状态为「待核实」的任务数；
  - 已完成：当前时间范围内状态为「已完成」的任务数；
  - 属实/不属实：在「已完成」任务中按核实结果分别统计。
- 图表口径：优先基于当前时间范围内任务数据生成（如每日完成数、属实占比等）。无数据时展示灰色占位或「暂无数据」。
- 最近完成任务列表口径：
  - 数据来源：当前时间范围内「已完成」任务列表；
  - 排序：按完成时间/任务时间倒序（最新在前）；
  - 筛选：支持「全部/属实/不属实」筛选，仅影响最近完成任务列表，不影响上方完成率与关键指标（若产品需联动，以设计为准）；
  - 分页加载：【已调整】默认加载最近 10 条；触底上拉后每次追加 10 条，直到无更多记录。

**按钮与交互**

- **时间维度按钮**：「本周」「本月」按钮互斥选中；点击某个按钮后，该按钮高亮，其余取消高亮，并触发本页所有统计与列表数据的重新计算与渲染，不跳转页面。
- **最近完成任务列表点击**：点击列表中的某条任务，打开「人机协同任务详情」页面，以只读模式查看该任务的详细信息和核实结果。
- **最近完成任务列表上拉加载**：【已调整】默认仅展示最近 10 条记录；用户滚动到列表底部后继续上拉（达到一定距离）触发加载动画，并再追加 10 条记录；重复上述操作直至没有更多记录，此时展示「已无更多记录」提示。筛选（全部/属实/不属实）切换时需重置为从最新 10 条重新开始加载。
- **返回按钮**：顶部返回按钮点击后，返回工作台首页。

**边界与异常**

- 当某个时间范围内没有任何任务数据时，应在完成率区域显示「0%」「0/0 任务」，关键指标全部为 0，图表以灰色占位或「暂无数据」文案展示，最近完成任务列表为空态文案，而不是空白。
- 若切换时间维度时数据加载失败或接口异常，应保留上一次成功的统计结果，并在页面显著位置提示「数据加载失败，请稍后重试」等信息。
- 点击最近完成任务列表项进入详情后，从详情返回本页时，应保持用户之前选择的时间维度与滚动位置，避免打断阅读体验。

#### 2.1.9 重点工作页面

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「重点工作」，右侧无按钮。主体为可滚动区域：第一行为「统计范围」与「时间维度」；第二块为三类作业统计卡片（巡视作业、操作作业、安全作业）；第三块为「最近作业」列表。

**第一行：统计范围 + 时间维度**

- **统计范围**：左侧文案「统计范围」，中间为数字（如 12），右侧单位「个站点」。该数字表示当前统计涉及的站点总数，随时间维度或数据源变化。
- **时间维度**：右侧三个按钮：「今日」「本周」「本月」。默认选中「本周」。点击某一按钮后，该按钮变为选中态（如高亮），下方所有统计卡片与「最近作业」列表的数据按所选时间范围重新计算并刷新。

**第二块：三类作业统计卡片**

- 三张卡片横向或纵向排列，每张结构一致，仅类型与数据不同。
- **第一张：巡视作业**
  - 卡片头部：左侧图标/标签「巡」，中间标题「巡视作业」，右侧「站点数」+ 数字（如 8）。
  - 任务完成率：一行文案「任务完成率」，下一行为百分比数字（如 79.2%）+ 一条横向进度条（宽度与百分比一致）。
  - 详情行：三个统计项并列——「已完成」+ 数字、「待完成」+ 数字、「逾期」+ 数字。
- **第二张：操作作业**
  - 结构同上。头部为「操」+「操作作业」+「站点数」+ 数字。任务完成率 + 进度条。详情行为「已完成」「待完成」「逾期」三列数字。
- **第三张：安全作业**
  - 结构同上。头部为「安」+「安全作业」+「站点数」+ 数字。任务完成率 + 进度条。详情行为「已完成」「待完成」「逾期」三列数字。

**数据展示规则**

- 统计范围数字：当前时间范围内参与统计的站点总数。
- 每张卡片的「站点数」：该类型作业涉及的站点数。
- 任务完成率：已完成任务数 / 该类型总任务数（百分比）；进度条宽度与百分比一致。
- 已完成、待完成、逾期：均为该类型作业在所选时间范围内的任务数量。数据来源与接口由业务约定（可与智能安全、巡视等模块数据一致或独立统计）。

**第三块：最近作业**

- 区块标题：「最近作业」。
- 列表：每条为一行，左侧为作业名称（如「10kV线路巡视」）、下方或副行显示「巡视作业 · 截止 2026-02-15」；右侧为状态标签：「已完成」「进行中」「待执行」等。列表条数、排序与数据由接口或业务约定。点击某条是否跳转（如进入智能安全并定位该作业）由产品约定。

**按钮与交互**

- **返回**：返回工作台首页。
- **时间维度按钮**：点击后仅刷新本页数据，不跳转。

**边界与异常**

- 无数据时各数字显示 0，进度条宽度 0%；列表为空时可展示空态文案。

#### 2.1.11 质量看板页面

**页面布局**

- 顶部导航栏：左侧返回箭头，中间标题「质量看板」，右侧无按钮。主体为可滚动区域，包含两大区块：一、终端统计看板；二、三类排名（缺陷排名、在线率排名、使用率排名），每类均可切换「前10名」「后10名」。

**第一区块：终端统计看板**

- **区块头部**：左侧标题「终端统计看板」，右侧时间维度按钮「本周」「本月」。默认选中「本月」。切换后本区块与下方排名数据一并按所选时间范围重算。
- **内容**：同一行三张统计卡片（或自适应换行）。
  - **第一张**：标签「终端在线率」，数值如「96.5%」。
  - **第二张**：标签「终端离线率」，数值如「3.5%」。
  - **第三张**：标签「终端数量」，数值如「74 台」。
- 在线率/离线率可为所选时间范围内全部站点的终端加权平均；终端数量为总终端台数。数据由接口或按站点数据汇总计算。

**第二区块：三类排名**

- 三个排名块纵向排列，结构相同，仅标题与排序维度不同。每个块内可独立切换「前10名」「后10名」。
- **第一块：缺陷排名**
  - 头部：左侧标题「缺陷排名」，右侧两个按钮「前10名」「后10名」。默认「前10名」选中。
  - 列表：最多 10 行。每行从左到右为：排名序号（1–10）、站点名称（如「110kV 城东站」）、缺陷统计（格式如「识别数/总缺陷数（识别率%）」，如「2/3（67%）」）。识别率可按颜色区分（如 ≥95% 绿、85%–95% 黄、&lt;85% 红）。「前10名」为识别率从高到低；「后10名」为从低到高。
- **第二块：在线率排名**
  - 头部：「在线率排名」+「前10名」「后10名」。
  - 列表：每行为排名、站点名称、在线率统计（如「18/18（100%）」表示在线终端数/该站终端总数（百分比））。前10名为在线率从高到低，后10名为从低到高。数值样式可按区间区分。
- **第三块：使用率排名**
  - 头部：「使用率排名」+「前10名」「后10名」。
  - 列表：每行为排名、站点名称、使用率统计（格式同在线率）。前10名/后10名按使用率高低排序。

**数据展示规则**

- 终端统计看板：在线率、离线率、终端数量均基于当前时间范围内各站点数据汇总或接口直接返回。
- 排名列表：数据源为各站点在所选时间范围内的缺陷（总缺陷数、识别数、识别率）、在线率、使用率。每个站点一行；前10名取排序后前 10 条，后10名取排序后后 10 条（即表现最差的 10 个）。缺陷排名按识别率排序；在线率/使用率按百分比排序。

**按钮与交互**

- **返回**：返回工作台首页。
- **时间维度**：切换本周/本月后，终端统计与三个排名列表全部按新时间范围重算并刷新。
- **前10名/后10名**：在每个排名块内独立切换；点击后该块仅重绘对应列表，其它块不受影响。选中态在对应按钮上高亮。

**边界与异常**

- 站点数不足 10 时，前10名/后10名列表条数按实际条数展示。无数据时终端统计显示 0% 或 0 台，排名列表为空或占位文案。

### 2.2 告警中心

#### 2.2.1 告警中心首页

**页面布局**

- 作为底部导航「告警」的目标页。顶部导航栏：左侧无按钮或返回（若从子页进入），中间标题「告警中心」；无右侧按钮。主体为可滚动区域，自上而下三块：**安全告警**卡片、**巡视告警**卡片、**跳闸告警**卡片。每块为独立卡片样式（圆角、阴影或边框），点击整块卡片打开对应类型的「告警详情」弹窗。底部导航「告警」入口上可有角标，数字为三类未读告警总数，为 0 时不显示角标。

**功能内容与样式**

- **安全告警卡片**
  - 卡片标题：固定文案「安全告警」。
  - 副标题/摘要：有未读时展示「X 条未读」或「待处理 X 条」；无未读时展示「暂无安全告警」。
  - 时间：展示最近一条告警的时间（如 yyyy-MM-dd HH:mm），无数据时展示「暂无」。
  - 可选：卡片右侧箭头或「查看」提示，表示可点击进入详情。
- **巡视告警卡片**
  - 卡片标题：固定文案「巡视告警」。
  - 副标题/摘要：有未读时展示未读条数或「待核实 X 条」；无数据时「暂无巡视告警」。
  - 时间：最近一条巡视相关告警时间，无则「暂无」。
- **跳闸告警卡片**
  - 卡片标题：固定文案「跳闸告警」。
  - 副标题/摘要：有未读时展示未读跳闸事件数；无则「暂无未读跳闸告警」。
  - 时间：最近未读跳闸事件时间，无则「暂无」。

**数据展示规则**

- **数据来源**：三类卡片的数据分别来自智能安全相关作业项（安措执行、作业过程、作业终结等待办/未读）、人机协同待核实任务、跳闸事件未读列表；与工作台各入口角标数据源一致。
- **未读规则**：各模块内「未读」「待处理」「待核实」的判定与智能安全、人机协同、智能跳闸页内规则一致；在告警中心仅做聚合展示。
- **角标**：底部导航「告警」角标 = 安全告警未读数 + 巡视告警未读数 + 跳闸告警未读数；任一来源数据异常时按 0 处理，避免角标异常。

**按钮与交互**

- **点击安全告警卡片**：在页面中央或底部弹出「告警详情」弹窗，弹窗标题为「安全告警」，列表为该类告警条目；关闭弹窗后不自动跳转。
- **点击巡视告警卡片**：弹出「告警详情」弹窗，标题为「巡视告警」，列表为巡视相关告警条目。
- **点击跳闸告警卡片**：弹出「告警详情」弹窗，标题为「跳闸告警」，列表为跳闸事件条目。
- 弹窗关闭方式：关闭叉号、点击遮罩关闭；关闭后停留在告警中心首页。

**边界与异常**

- 三类卡片均无数据时：各卡片展示「暂无xxx告警」及「暂无」时间，角标不显示；点击卡片仍可打开弹窗，弹窗内列表为空态（见 2.2.2）。
- 数据加载失败：可展示「加载失败，请稍后重试」或保留上次缓存数据，由产品约定。
- 从其他页面（如智能安全）通过「告警中心」入口进入时，若需刷新未读数，进入时应拉取最新数据并更新角标与卡片摘要。

#### 2.2.2 告警详情弹窗

**页面布局（弹窗结构）**

- 弹窗类型：底部弹出或居中蒙层弹窗，带遮罩。标题栏：左侧无或标题居中，右侧关闭叉号；标题文案为当前告警类型（「安全告警」「巡视告警」「跳闸告警」）。主体为列表区域，可纵向滚动；列表为空时展示空态文案。列表项：每条为一张卡片或一行可点击项，**标题（级别+标题文案）与下方正文（关联作业、摘要等）之间保留约 5px 间距**，避免与全局详情样式冲突导致遮挡或过紧。

**功能内容与样式**

- **安全告警列表**
  - 每条展示：级别标签（如紧急/提醒/通知，不同颜色区分）、标题文案、关联作业（作业项名称）、摘要（一行或两行截断）、时间；右侧或底部按钮「去处理」。

  - 列表为空时：展示「暂无未读跳闸告警」。
- **巡视告警列表**
  - 每条展示：任务/设备名称、描述摘要、时间等；可带「去处理」或直接点击整条。
  - 列表为空时：展示「暂无巡视告警」。

**数据展示规则**

- 列表数据与告警中心首页该类型卡片的数据源一致；进入弹窗时按该类型拉取未读/待处理列表，按时间倒序或按业务规则排序。
- 单条告警需携带：唯一 ID、类型、关联业务（作业项 ID / 跳闸事件 ID / 人机协同任务 ID），用于点击后跳转并定位到对应页面与 Tab。

**按钮与交互**

- **安全告警**：点击某条或「去处理」→ 关闭弹窗，将该条标记为已读，跳转到智能安全页面，并自动选中该条对应的作业项、切换到对应 Tab（安措执行/作业过程/作业终结）；工作台角标与告警中心角标更新。
- **跳闸告警**：点击某条 → 关闭弹窗，将该事件标记为已读，跳转到智能跳闸页面并自动选中该条事件，默认显示跳闸快报 Tab；工作台跳闸角标与告警中心角标更新。
- **巡视告警**：点击某条 → 关闭弹窗，标记已读，跳转到人机协同任务详情或待核实列表并定位到该任务（按产品约定）。
- **关闭**：关闭叉号、点击遮罩关闭弹窗；关闭后不自动跳转，停留在告警中心首页。

**边界与异常**

- 列表为空时：不展示列表项，仅展示空态文案，不展示「去处理」按钮。
- 点击后跳转失败（如该条已被处理、数据失效）：可提示「该告警已处理或不存在」，并关闭弹窗、刷新告警列表；角标需同步更新。
- 弹窗内列表过长时，仅列表区域可滚动，标题栏与关闭按钮固定。

**功能内容与样式**

- **欢迎语**：无历史消息时展示一句欢迎语，如「你好！我是小智，有什么可以帮助你的吗？」。
- **对话区域**：用户输入内容并点击发送（或回车）后，用户消息与助手回复依次追加展示。**展示规范**：用户消息在右侧、助手消息在左侧；气泡宽度随内容自适应，避免右侧大面积留白。**头像**：用户消息使用统一头像图片（如 image/common/头像.png），助手消息使用机器人图标。对话内容支持前端模拟或对接对话接口，由产品/接口约定。
- **数据问答与图表**：小智支持根据用户提问返回**数据统计文案**或**内嵌图表**。示例提问与回复形式：
  - **数据问答**：用户可输入如「本月告警数量」「告警多少」「作业完成率」「巡视数据」「上周巡视数据」「设备数量」等，小智返回对应统计文案（如本月告警条数、完成率、巡视计划与完成项等）；同一类问题可有多种表述随机展示，避免固定话术。
  - **图表展示**：用户可输入如「趋势图」「告警趋势」「柱状图」「饼图」「占比」等，小智在回复中展示内嵌图表（折线图/柱状图/饼图），并配简短说明文案。数据可为前端模拟，后续可对接真实数据或对话接口。
- **输入框**：单行输入，占位符如「发消息或按住说话…」；支持回车发送。发送后输入框清空，消息追加到对话区。

**按钮与交互**

- **发送**：将当前输入内容作为用户消息展示，并请求助手回复（或模拟回复），回复展示在对话区；支持数据/图表类回复时在气泡内展示图表。
- **场景选择器**：点击后展开下拉，选项如「巡视应用」「分析应用」等；选中某项后，顶部场景文案更新为该选项，并可切换下方快捷入口的显示（如巡视应用显示巡视相关入口）。点击页面其他区域收起下拉。
- **快捷入口**：快捷按钮如「巡视数据问答」「巡视计划创建」「巡视计划查找」等，点击后可在输入框填入对应预设问题，用户可再编辑后发送。

**数据与边界**

- 新建对话、发送消息、历史记录与后端接口的对接由产品约定；数据问答与图表可先采用前端模拟数据，页面需保留输入框与发送入口，便于后续接真实对话或数据接口。

#### 2.3.2 历史对话侧边栏

**布局**

- 从左侧或右侧滑出的侧边栏。标题为「历史对话」或同类；有关闭按钮。列表为历史对话项，每项显示该对话的标题（或首句摘要）；每项可有操作：编辑名称、删除。底部可有「新建对话」按钮。

**功能内容与样式**

- **历史项**：点击某一项（非编辑/删除按钮）时，切换当前主界面对话内容为该条历史对话，并关闭侧边栏。
- **编辑名称**：点击后可修改该条对话的标题（弹窗输入或内联编辑），确认后更新展示。
- **删除**：点击删除后二次确认（如「确定删除该对话？」），确认后从列表移除该条并关闭侧边栏或保持打开由产品约定。
- **新建对话**：点击后清空当前对话区（或进入新会话），并关闭侧边栏。

**打开与关闭**

- 小智页面的菜单按钮打开本侧边栏；关闭按钮或点击遮罩关闭。
